# DSH 启动动画 · 安装说明

给 **DSH 桌面端**加一段开屏演出：真实读取本机的 skills 与已加载 plugins，配固定英文旁白，演完自动进入 Harness。

## 安装（约 30 秒，无需 Python / npm / Rust）

1. 确认这台电脑**已安装 DSH 桌面端**，并且**至少启动过一次**（安装器需要读它的配置目录）
2. 双击 **`安装.cmd`**
3. 看到「安装完成！」后，**完全退出并重新启动 DSH** → 开屏动画即会播放

## 播放时能做什么

| 操作 | 效果 |
|---|---|
| **中心图标悬停约 1 秒** | **指纹式读条**（细环从 12 点左右对开向下、正下方汇合）→ 读满即进入；中途移开则回退 · 序章与身份确认屏都可用 |
| 点击画面 / `Enter` | 开始播放；播放中推进当前阶段 |
| **连按两次 `Space`**（320 ms 内） | 紧急中止 → 2.4 秒红黑确认面板 → 直接进入 Harness |
| `Ctrl` + `Alt` + `P` | **随时重播一遍**（改动画资源后也无需重启） |
| `Esc` | 直接返回官方 Harness |

## 卸载

再运行一次 `安装.cmd`，或在 PowerShell 里执行：

```powershell
.\install.ps1 -Uninstall
```

它只移除安装器自己写入的那段**标记块**，不会动你 profile 里的任何其它设置。

## 其它参数

```powershell
.\install.ps1 -DryRun             # 只看会改什么，不落盘
.\install.ps1 -ProfileName <名字>     # 指定 profile（默认自动选 desktop）
.\install.ps1 -DshHome <路径>        # 指定 DSH_HOME（默认 %USERPROFILE%\.dsh）
```

改写 `cordis.patch.yml` 前，会在同目录自动留一份 `cordis.patch.yml.bak-startup-<时间戳>` 备份。
